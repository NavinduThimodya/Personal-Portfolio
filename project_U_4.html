Smart Mirror with Home
Automation Integration

Project Details

Role: Group

1. Project Overview

Designed and built an interactive Smart Mirror that serves as a central hub for personal information and home automation control. The system integrates a two-way mirror with a display monitor powered by a Raspberry Pi, providing users with real-time updates on weather, news, and calendar events while functioning as a standard mirror.

2. Key Features & Implementation

Hardware Design

  • Constructed a custom wooden frame housing a 24-inch LED monitor and a two-way acrylic mirror.
  • Integrated a Raspberry Pi 4 Model B as the core processing unit, optimizing thermal management with active cooling for 24/7 operation.

Software Ecosystem

  • Deployed the MagicMirror² open-source modular platform to render dynamic widgets (clock, weather forecast, news feed).
  • Developed custom Python scripts to interface with Home Assistant via MQTT, enabling the mirror to display status updates of smart home devices (e.g., lights, thermostat).

Voice & Gesture Control

  • Integrated Google Assistant SDK to enable voice commands for controlling the display (e.g., "Turn screen on/off", "Show map").
  • Implemented a gesture sensor (PAJ7620) to allow touch-free page switching, preventing fingerprints on the mirror surface.

Facial Recognition

  • Utilized OpenCV and a Raspberry Pi Camera Module to identify registered users and load personalized profiles (e.g., specific calendars or transit routes).

3. Technologies & Tools Used

Raspberry Pi 4 Python MagicMirror² MQTT Home Assistant Google Assistant SDK OpenCV
