Neuro-Steered Speaker Extraction:
Fusion of Speech and EEG Signals

Project Details

Type: Undergraduate Research Project
Status: Mid-Evaluation Complete (Ongoing)

1. Project Overview

Designed and implemented a deep learning framework to solve the "Cocktail Party Problem" for assistive hearing technology. The system utilizes Electroencephalography (EEG) signals to track a user's auditory attention and isolate a specific target speaker from a noisy, multi-speaker environment. The project introduces a novel Hierarchical Fusion Strategy that aligns brain signals with speech at multiple temporal scales, surpassing traditional static vector approaches.

2. Technical Implementation

Hierarchical Fusion Architecture

  • Fusion Module: Developed a fusion module that aligns EEG features with specific layers of a frozen Wav2Vec 2.0 model: Layer 1 for Acoustic features, Layer 4 for Linguistic features, and the Final Layer for Semantic context.
  • Cross-Modal Attention: Implemented Cross-Modal Attention mechanisms to weigh the relevance of speech features based on neural attention.

Dual-Path Pipeline

  • Discriminative Path: Built a real-time extraction pipeline using a mask-estimation approach, optimized for low latency.
  • Generative Path: Adapted the "SoloSpeech" diffusion model to create an EEG-conditioned generative pipeline for high-fidelity waveform reconstruction.

Signal Processing & Optimization

  • Multi-scale EEG Encoder: Engineered using Temporal Convolutional Networks (TCN) with exponentially expanding receptive fields to capture both fast transient and slow cortical rhythms.
  • Efficiency: Addressed high-dimensionality EEG data by utilizing Depthwise-Separable 1D Convolutions to improve parameter efficiency.
  • Performance: Reduced training time from 2 hours to 15 minutes per epoch by implementing advanced data handling (LMDB caching) on NVIDIA A100 cloud GPUs.

Results

  • Metrics: Achieved a Scale-Invariant Signal-to-Distortion Ratio (SI-SDR) of 11.374 dB, marking a ~5.6 dB improvement over the baseline and performing competitively with State-of-the-Art models like NeuroHeed.
